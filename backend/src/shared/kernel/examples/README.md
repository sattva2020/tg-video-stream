# Examples - Clean Architecture Patterns

Эта директория содержит практические примеры использования паттернов Clean Architecture.

Эти примеры предназначены для:

1. **Обучения** — понимание паттернов на практике
2. **Копирования** — быстрый старт новой функциональности
3. **Референса** — проверка правильности реализации
