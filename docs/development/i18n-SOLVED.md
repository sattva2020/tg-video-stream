## 🚀 Как проверить работу

### Шаг 1: Перезапустите frontend
```bash
cd frontend
npm run dev
```

### Шаг 2: Откройте браузер
Перейдите на: `http://localhost:3000`

### Шаг 3: Найдите панель отладки
В **правом нижнем углу** экрана должна появиться панель:

```
┌─────────────────────────────────┐
│ 🔍 i18n Debug Panel             │
├─────────────────────────────────┤
│ Текущий язык: ru                │
│ Загруженные языки: ru, en, ...  │
│                                 │
│ Тестовые переводы:              │
│ • admin.dashboard: Панель...    │
│ • admin.users: Пользователи     │
│ • admin.stream: Трансляция      │
│                                 │
│ [RU] [EN] [UK] [ES]             │
└─────────────────────────────────┘
```

### Шаг 4: Проверьте переводы на странице
- Откройте админ-панель
- Все тексты должны быть на русском языке
- Переключите язык через панель отладки
- Переводы должны меняться

### Шаг 5: Проверьте консоль (F12)
Должны быть логи:
```
i18next: languageChanged ru
i18next: initialized {debug: true, lng: 'ru', ...}
```

## 🔧 Ручная диагностика (если нужно)

Откройте консоль браузера (F12) и выполните:

```javascript
// 1. Проверить текущий язык
window.localStorage.getItem('i18nextLng')
// Должно вернуть: 'ru'

// 2. Проверить конкретный перевод
window.i18next?.t('admin.dashboard')
// Должно вернуть: 'Панель управления'

// 3. Проверить все ресурсы
window.i18next?.store?.data
// Должен показать объект с языками и переводами

// 4. Очистить кэш (если нужно)
localStorage.removeItem('i18nextLng');
location.reload();
```

## 🎨 Панель отладки

### Показывается автоматически
- ✅ В режиме разработки (DEV)
- ✅ Если в localStorage есть `i18n_debug = true`

### Включить в продакшене
```javascript
localStorage.setItem('i18n_debug', 'true');
location.reload();
```

### Отключить
```javascript
localStorage.removeItem('i18n_debug');
location.reload();
```
