# Frontend: безопасная загрузка HeroUIProvider (исправление пустого экрана)

## 🔴 Проблема
На продакшене при открытии лендинга отображалась пустая страница. В консоли браузера фиксировалась ошибка:
`Cannot access 'M' before initialization` (index.mjs:43). Из-за ошибки модуль UI-библиотеки не загружался, и приложение падало до рендера.

## 🔄 Шаги воспроизведения
1. Открыть https://sattva-streamer.top/
2. Наблюдать пустой экран
3. Открыть DevTools → Console
4. Увидеть `Cannot access 'M' before initialization` в index.mjs

## 🔍 Корневая причина
UI-провайдер из `@heroui/react` загружался синхронно в стартовом бандле. При инициализации модуля возникала ошибка TDZ, из-за чего весь рендер приложения прерывался.

## ✅ Решение
Заменили прямой импорт `HeroUIProvider` на безопасную обёртку с динамической загрузкой:
- `HeroUIProviderSafe` пытается загрузить `@heroui/react` через `import()`.
- При ошибке загрузки приложение продолжает работать без провайдера.
- Ошибка логируется в консоль для диагностики.

## 📁 Изменённые файлы
- [frontend/src/components/providers/HeroUIProviderSafe.tsx](../../frontend/src/components/providers/HeroUIProviderSafe.tsx) — безопасная динамическая загрузка провайдера.
- [frontend/src/main.tsx](../../frontend/src/main.tsx) — переход на `HeroUIProviderSafe`.
