# FRONTEND: /schedule — паритет «цветной» стилистики карточек с Dashboard V2

- Дата: 2025-12-20
- Автор: Jarvis (GitHub Copilot)

## 🔴 Проблема

Страница `/schedule` визуально отличалась от Dashboard V2: верхний блок с карточками и заголовки выглядели более «плоскими» и не использовали уже существующий “цветной” паттерн (градиентные бейджи и мягкое акцентное свечение), принятый в Dashboard V2.

## 🔄 Шаги воспроизведения

1. Открыть `/dashboard` (Dashboard V2).
2. Зафиксировать стиль карточек: градиентный бейдж-иконка + мягкое подсвечивание.
3. Открыть `/schedule`.
4. Сравнить верхний блок карточек и заголовки.

**Ожидаемо:** `/schedule` в том же визуальном языке, что Dashboard V2.

**Фактически:** карточки/заголовки более нейтральные и визуально «не из этой системы».

## 🔍 Корневая причина

На `/schedule` использовались нейтральные контейнеры (панель + `border/ring`) и акцент через `--color-accent`, но не переиспользовался готовый Dashboard V2 паттерн:

- `StatCard` (градиентный бейдж с белой иконкой + мягкий градиентный hover-оверлей)
- градиентные бейджи в заголовках

## ✅ Решение

1. Верхний блок статистики `/schedule` переведён на компонент `StatCard` (существующий Dashboard V2), без изменения UX/логики.
2. Заголовок страницы `/schedule` получил градиентный бейдж-иконку (как в Dashboard V2).
3. Заголовок блока календаря (`ScheduleCalendar`) получил такой же градиентный бейдж.

## 📁 Изменённые файлы

- [frontend/src/pages/SchedulePage.tsx](../../frontend/src/pages/SchedulePage.tsx) — `StatCard` для верхних карточек + градиентный бейдж в заголовке.
- [frontend/src/components/schedule/ScheduleCalendar.tsx](../../frontend/src/components/schedule/ScheduleCalendar.tsx) — градиентный бейдж в заголовке блока.
