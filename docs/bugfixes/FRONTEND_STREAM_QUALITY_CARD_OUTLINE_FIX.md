# FRONTEND: Обводка блока «Качество текущего трека» в тёмной теме (Dashboard V2)

- Дата: 2025-12-20
- Автор: Jarvis (GitHub Copilot)

## 🔴 Проблема

В админ-панели (Dashboard V2) карточка «Качество текущего трека» визуально выбивалась из общего стиля в тёмной теме: контур/обводка читались хуже, чем у остальных карточек.

## 🔄 Шаги воспроизведения

1. Открыть Dashboard V2.
2. Включить тёмную тему.
3. Сравнить карточку «Качество текущего трека» с соседними карточками.

**Ожидаемо:** визуально согласованный контур/обводка как у остальных блоков.

**Фактически:** карточка выглядит менее отделённой от фона (контур слабый).

## 🔍 Корневая причина

`StreamQualityCard` использовал только `border` без дополнительного `ring`-контура и мягкого разделения через тень, поэтому на тёмном фоне границы воспринимались слабее, чем у карточек, приведённых к стандартному паттерну `border + ring`.

## ✅ Решение

Применён устойчивый паттерн карточек для тёмной темы:

- Добавлено: `ring-1 ring-inset ring-[color:var(--color-border)]`.
- Добавлено мягкое разделение с фоном: `shadow-md shadow-black/5`.
- Сохранено: `border border-[color:var(--color-border)]` и фон панели.
- Для визуальной консистентности добавлено: `rounded-2xl`.

## 📁 Изменённые файлы

- [frontend/src/components/dashboard/StreamQualityCard.tsx](../../frontend/src/components/dashboard/StreamQualityCard.tsx) — обновлён внешний wrapper карточки (ветка без streamUrl и основная ветка).

## 🧪 Тестирование

1) Визуальная проверка:

- Открыть Dashboard V2 в тёмной теме.
- Убедиться, что у «Качество текущего трека» контур/обводка совпадают по восприятию с соседними карточками.

Если браузер показывает старый вид, сделать принудительное обновление:
