# Technology Stack

## Backend

*   **Language:** Python 3.x
*   **Framework:** FastAPI
*   **Telegram Libraries:** Pyrogram, PyTgCalls
*   **ORM:** SQLAlchemy
*   **Database:** PostgreSQL (primary), SQLite (testing)
*   **Caching/Messaging:** Redis

## Frontend

*   **Language:** TypeScript
*   **Framework/Library:** React
*   **Build Tool:** Vite
*   **Web Server:** Nginx

## Other Core Technologies

*   **Video Transcoding:** Rust (custom microservice using FFmpeg)
*   **Containerization:** Docker, Docker Compose (deployment using Docker Swarm as per product.md)
*   **Monitoring:** Prometheus, Grafana, Alertmanager

## Development Tools & Practices

*   **Code Formatting:** Black (Python)
*   **Import Sorting:** isort (Python)
*   **Linting:** Ruff (Python)
*   **Testing:** Pytest (Python)
*   **Dependency Management:** pip (Python), npm (Node.js/TypeScript)
